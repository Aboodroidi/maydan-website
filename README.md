# Maydan — Website

Marketing site for **Maydan**, the easiest way to discover and book football
pitches across Muscat, Oman.

Static, bilingual (English / Arabic with RTL), single page: About, Services,
and a "coming soon" download section. Built with the Maydan brand fonts (Winco)
and logos.

## Structure

```
index.html
assets/
  css/styles.css
  fonts/        Winco font family
  img/          logos, watermark, app icon
```

## Deploy

It's a plain static site — upload the contents (so `index.html` is at the web
root, e.g. Plesk `httpdocs`). No build step required.
